GHAR TAK

Same street. Same words. Every day.

Every day, women walk home through harassment, judgment and pressure.
This game turns those moments into obstacles.
Dodge them. Speak up. Break the loop.
👤 PLAYER: Player
Content Note: This game portrays everyday harassment and social pressure faced by women. Player discretion advised.

WHY THIS GAME EXISTS

Every day, women and girls walk home through the same streets and face the same things:

⚠️ STREET HARASSMENT

strangers who catcall, follow and block her path.

🗣️ GOSSIP & SHAMING

neighbours judging when she comes home and who she's with.

📄 MARRIAGE PRESSURE

being pushed to marry before she's ready.

🧣 DRESS-CODE POLICING

being scolded for what she wears.

For too many women this isn't a game. It's a loop.

YOUR GOAL: Walk her home. Dodge what you can, endure what you can't, collect Courage and SPEAK UP to all four, until the loop breaks.

👥 The 4 People: Social Pressures

Real-world pressures women face every evening become obstacles in her path:

⚠️
The Gunda (Street Harassment)

Staggering drunkards who catcall and block her path. Dodge early into a free lane.

🗣️
The Gossip Aunties (Shaming)

Judging neighbours whose whispered gossip sweeps lanes. Avoid their gossip zone.

📄
The Marriage Uncle (Marriage Pressure)

Pushy uncles stepping into your lane with rishta biodatas. Anticipate his side-step.

🧣
The Dress-Code Aunty (Moral Policing)

Balcony aunties scolding clothes. Slide under her swinging dupatta or switch lane.

💥 SPEAK UP! & Break The Loop

Silence harassment and social judgment to break free from the endless cycle:

📢 "BAS! BAHUT HO GAYA!"

When the Courage Meter is 100% full, press SPACEBAR or tap the glowing SPEAK UP button.

⚡ Slow-Mo Shockwave: Slows down time and blasts all nearby obstacles back.

🔓 Unlock All 4 Voices: Speak up to each character across days to permanently BREAK THE LOOP!

🎮 GAME ENGINE & CODE
Game Engine
100% original Vanilla JavaScript (ES5/ES6), HTML5 Canvas 2D API. No external game framework used.
Original work — All rights reserved by the development team.
Web Audio Engine
Procedural SFX, music step sequencer, and 3D stereo panning built entirely on the native Web Audio API.
Original work — No third-party audio library used.
Voice & Dialogue System
Character dialogue delivered via native Web Speech API (SpeechSynthesis) using system-installed voices. Falls back to procedural blip-talk tones.
Web Speech API — W3C Community Specification. System voices are provided by the user's OS and browser; no third-party voice assets bundled.
🎨 ART & GRAPHICS
All Sprites & Characters
Every character, obstacle, environment element, pickup icon, and VFX is drawn procedurally at runtime using the HTML5 Canvas 2D drawing API. No external image files are loaded or bundled.
Original work — All rights reserved by the development team.
UI Icons (Emoji)
Inline Unicode emoji characters (e.g. ❤️ 📢 🚶‍♀️) used in HUD labels and tutorial illustrations. Rendered by the user's OS emoji font.
Unicode Standard — Open standard. Specific emoji artwork rendered by the OS/browser font (Noto Emoji, Apple Color Emoji, Segoe UI Emoji, etc.). No custom emoji images bundled.
Background / Environment Art
Indian street skyline, road, shop signs, streetlights, and scrolling props are drawn procedurally. All text in shop signs is fictional Hinglish.
Original work — All rights reserved by the development team.
🔤 FONTS & TYPOGRAPHY
UI & Body Font
System font stack: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif. No external font files loaded.
System fonts — Each font is owned by its respective vendor (Apple, Microsoft, Google, etc.) and is pre-installed on the user's device. No licencing required for use via CSS font stack.
Canvas Text Rendering
In-game labels, subtitles, score display, and dialogue text use ctx.font with the same system font stack rendered directly onto the Canvas.
Same as above — No external font files.
🔊 AUDIO & SOUND
Music
Procedurally generated adaptive soundtrack using a step sequencer built on the Web Audio API. Adapts tempo and instrumentation based on game state (day/night, high danger, Speak Up).
Original work — All rights reserved by the development team.
Sound Effects
All SFX (footsteps, heartbeat, coin collect, shockwave, coin blips, jump, slide, crash, danger pulse) are synthesised at runtime using oscillators and noise generators via the Web Audio API.
Original work — No external SFX library used.
Dialogue Voice Lines
Character dialogues are spoken via the browser's built-in SpeechSynthesis API. The voice is determined by the language/pitch preset and the system voices installed on the player's device. No audio clips are bundled.
Web Speech API — W3C Community Specification. System voices are the user's property.
Audio assets/audio/ directory
The assets/audio/ directory is reserved for optional drop-in .mp3 replacements. No audio files are currently bundled. The directory contains only a README.md placeholder.
N/A — No bundled audio files.
